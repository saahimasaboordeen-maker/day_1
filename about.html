About My Project

Learn more about our Students Information System.

The Students Information System is an achievement during my internship, as I created a web application that could help to easily gather and manage information about students. By using HTML, CSS and Bootstrap, I have created an attractive, multipage frontend application that is able to adjust to any screen size, and can be linked with the backend database in the future. It gave me a chance to gain some practical skills in the field of web design, allowing me to learn more about responsive layouts and creating forms.
